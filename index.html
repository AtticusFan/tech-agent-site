GPT-6 Cyber：漏洞研究能力提升，評測結果須連同授權範圍閱讀

GPT‑6 Cyber: Advancing the frontier of aligned cybersecurity agents

OpenAI 公布 GPT-6 Cyber 在 ExploitGym 的成績為 48.5%，前代 GPT-5.6 Cyber 為 32.1%。

02AI 治理本期必讀

Claude 內容溯源：文字浮水印與 C2PA 需分開理解

How Claude marks AI-generated content

Anthropic 說明，Claude 使用文字內嵌浮水印，以及檔案的 Content Credentials（C2PA）標記內容。

官方明確指出，沒有偵測到標記，不代表內容未經 AI 生成或處理。

為何入選

這是推論：內容驗證與稽核流程需要區分文字訊號和檔案來源憑證；把未偵測到標記直接當成人工原創證明，會造成判讀錯誤。

EN / Text watermarks and C2PA are provenance signals; an absent mark does not prove human authorship.

證據與限制

依據官方說明與短摘錄；頁面僅顯示本週更新，無法確認精確發布日期。不同模型、平台與內容類型的支援範圍不同；這些標記不能單獨證明完整來源，也不是法律遵循認證。

LLM 0.37：增加相容端點設定，擴充多模態 embedding 介面

llm 0.37

Simon Willison 發布 LLM 0.37，新增 llm openai endpoint add 命令，方便設定使用 OpenAI 相容端點的模型。

此版讓 embedding 介面接受不同二進位內容型別；作者以能處理文字、音訊、圖片與影片的 Gemini Embedding 2 為例。

為何入選

這是推論：統一模型端點及 embedding 輸入型別，可作為檢索實驗工具鏈的觀察項目；實際整合仍需核對模型與外掛的支援範圍。

EN / LLM 0.37 expands endpoint configuration and typed embedding inputs for multimodal model integrations.

證據與限制

依據作者版本公告，未在本站環境測試各供應商整合。介面擴充不代表所有模型都支援多模態，也不代表第三方 API 免費。

05研究與實作

Qwen 本機權重辨識實驗：有成功案例，也有失敗邊界

Qwen 3.8 27B on my laptop can interpret model weights, too

Simon Willison 以本機 Qwen 3.8 27B 嘗試從小型遊戲網路權重辨識行為，聚焦不使用工具的設定。

作者記錄了多個辨識案例，也明確指出 Freeway 提示測試失敗。

為何入選

這是推論：權重空間研究值得追蹤，但必須區分不使用工具的行為辨識，以及使用程式修改權重；兩者的證據與風險範圍不同。

EN / A local Qwen experiment explores behavior inference from tiny policy weights, with clear failures and scope limits.

證據與限制

單一作者的探索性重現，不是大型模型的通用可解釋性證明，也沒有證明能偵測模型投毒或後門。小型遊戲、長推論時間與未成功案例限制了可推廣性。
