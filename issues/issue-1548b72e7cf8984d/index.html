Understanding Failures in LLM Reasoning by Learning Structured Representations of Chain-of-Thought

MCP 工具名稱與提供者身分綁定不足的測量研究

When Tool Names Are Not Identities: Measuring Provider Misbinding in MCP-Based AI Agents

研究將合法提供者請求被導向攻擊者工具的情況定義為工具提供者誤綁定。

研究指出，名稱碰撞、任務相符描述與相容綱要同時存在時，誤綁定風險最明顯。

為何入選

這是推論：MCP 工具選擇若缺乏可驗證的提供者身分，可能把看似正常的工具呼叫導向攻擊者控制的服務。

MCP tool metadata may not reliably bind a tool to its legitimate provider.

證據與限制

僅讀取預印本摘要；實驗在受控 MCP 環境進行，未證明所有實際部署皆有相同風險。

BitBypass: A New Direction in Jailbreaking Aligned Large Language Models with Bitstream Camouflage

BitBypass investigates bitstream camouflage as a black-box jailbreak technique.

SilentAir 疑濫用電信互連攔截通話與簡訊

【資安日報】11月17日，國家級駭客組織SilentAir鎖定臺灣等十多個國家的手機用戶，濫用電信訊號攔截簡訊與通話

報導稱 SilentAir 攻擊範圍涵蓋臺灣在內十多個國家，目標包括政治人物與政府高階官員。

報導稱攻擊者大量使用不會在手機顯示或觸發通知的無聲簡訊。

為何入選

這是推論：電信互連與無聲簡訊若遭濫用，可能繞過終端通知並影響高價值帳號的簡訊驗證。

SilentAir is reported to abuse telecom interconnection and silent SMS for surveillance.

證據與限制

此篇為 iThome 二手整理，且歸因為電信資安業者 Enea 的揭露；未有獨立鑑識資料。
