LLM代理授權漂移：多步工具使用可能越界

Authorization Drift in LLM Agents: Evaluating Boundary Compliance in Multi-Step Tool Use

研究在13個模型、3個框架及25,207條軌跡中觀察到，能力較高的模型也可能出現授權漂移，漂移率為0.43至0.61。

86.18%的任務曾出現符合授權的成功軌跡，研究並指出早期過度蒐集資料是主要漂移來源。

為何入選

這是推論：研究把代理越權行為轉化為可測量的資料、工具、範圍與時間邊界，對企業代理治理具有直接參考價值。

The study finds that capable LLM agents can still drift beyond authorization boundaries.

Microsoft Intelligent Terminal 0.3支援代理背景執行

微軟Intelligent Terminal支援背景執行，關閉視窗不中斷AI代理任務

Intelligent Terminal 0.3新增背景執行模式，關閉終端機視窗後仍可繼續執行AI代理任務與程式編譯。

官方說明該機制保留現有行程，電腦重新開機或應用程式完全結束後無法續行。

為何入選

這是推論：背景執行與代理工作階段管理可改善長時間開發任務的操作連續性，但也使工作狀態與權限控管更需清楚。

Microsoft’s experimental terminal can keep agent tasks running after the window closes, but not across reboots.

內容來自二手報導；產品仍處於實驗性階段，未獨立測試不同代理與系統情境。
