Anthropic公布可驗證推論研究進展

Progress on provable inference for large language models

Anthropic發布FlashProve開源原型，探索以零知識證明驗證回應是否由指定模型產生。

在Llama 4 Maverick量化模型測試中，單次1,024-token請求的證明大小約為19 MB，但GPU時間約是vLLM的70至95倍。

為何入選

這是推論：若技術可持續改善，模型服務的完整性驗證可能成為治理、稽核與安全部署的重要基礎；目前仍是研究原型。

Anthropic released FlashProve, an open-source prototype for provable inference.

內容為Anthropic研究文章與其報告的結果，主要是原型展示；未見獨立重現或生產環境驗證。

Anthropic分析科學家如何使用Claude

How scientists use Claude

Anthropic以隱私保護方法分析20.7萬個Claude與Claude Code研究工作階段。

報告指出，資料分析約占Claude工作階段的三分之一，研究人員較少用Claude進行想法生成與資料蒐集。

為何入選

這是推論：研究把模型使用情形與科學工作流程連結，能協助評估AI對研究生產力的實際影響，但不等同於已證實的生產力提升。

Anthropic studied how scientists use Claude across research fields and tasks.

研究分析的是Anthropic消費方案工作階段的分類資料；樣本、分類器與研究方法由Anthropic說明，未見外部驗證。

LangChain分享如何最佳化Deep Agents瀏覽器操作

How We Optimized Browser Use for Deep Agents

LangChain比較七種工具組合後，宣稱Stagehand在WebVoyager的100項任務中通過率最高，達90%。

LangChain指出Stagehand的程式碼模式可減少模型往返，並讓每項任務平均使用10個步驟，而Playwright MCP為26個。

為何入選

這是推論：文章具體展示工具介面、上下文管理與評估設計如何影響瀏覽器代理的成本與成功率，對代理工程實作有直接參考性。

LangChain reports that tool design strongly affects browser-agent cost and success.

證據與限制

數據來自LangChain自選工具、模型與基準測試；屬發布者測試結果，未代表所有網站或代理設定。

OpenAI研究顯示AI助理仍難有效運用歷史對話

OpenAI揭露AI助理個人化瓶頸，模型仍難善用過往對話

iThome報導OpenAI的LifeVal評測涵蓋169項日常任務，模型在需要從歷史對話取得資訊的條件中平均達標率為33.33%。

當背景資訊被模擬放入歷史對話，相關條件達標率由55.8%降至41.5%。

為何入選

這是推論：個人化助理的瓶頸不只在模型能力，也在長期資訊檢索與情境判讀；這對記憶功能的產品設計與評估很關鍵。

OpenAI’s LifeVal report highlights persistent limits in using conversational history.

證據與限制

證據來自iThome對OpenAI研究的報導；完整任務資料集與評測程式未釋出，且未提供論文所用模型的完整資訊。

Anthropic擴大Claude文字浮水印支援並說明限制

How Claude marks AI-generated content | Claude Help Center

Anthropic說明，支援模型的生成文字會嵌入浮水印，檔案則可加入C2PA內容憑證。

官方提醒，偵測到Claude標記只表示內容可能曾由Claude生成或處理，並不能單獨確認完整來源。

為何入選

這是推論：生成內容標記與可偵測性直接涉及AI透明度、內容溯源與合規；官方同時明確說明標記不能單獨證明完整來源。

Anthropic is expanding Claude marking while emphasizing that detection is not conclusive.

證據與限制

內容來自Anthropic說明文件；浮水印偵測仍是私人預覽，且部分模型、參數與平台存在支援限制。
