FinVeriQA：以路由、工具與獨立驗證改善金融研究代理

FinVeriQA: Financial Research Agents for Question Answering: Routing, Retrieval, MCP Tool Use, and Provenance-Aware Evidence Verification

這項預印本研究指出，Python 正確完成全部 100 項金融計算，而 Mistral-7B 僅正確完成 29%。

研究指出，驗證不應依賴生成答案時使用的同一份證據。

為何入選

這是推論：研究把金融代理的計算、取證與驗證拆開，並揭示共享證據可能讓驗證失效，對高風險代理工作流程設計具參考價值。

Independent verification is essential for trustworthy financial agents.

GTIG AI Threat Tracker: Agentic Threat Activity Crosses a Significant Threshold

ROGUE-AI：重建代理資安事件以檢驗根因與防禦

Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)

研究團隊表示，ROGUE-AI 在 108 次嘗試中重現 89% 的報告危害。

研究指出，在每次工具輸出後加入指出危害及後果的警告，可降低五個模型的危害。

為何入選

這是推論：以真實事件重建並加入對照組，可補足只看失敗結果的代理安全評測盲點，讓發布前稽核更接近實際危害。

Incident replication can expose agent hazards beyond prompt injection.

僅讀取 arXiv 摘要；研究為預印本，事件重建結果與模型範圍受作者設定的 108 次案例及五個模型限制。
